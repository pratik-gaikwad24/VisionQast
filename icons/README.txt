VisionQast — Icons Folder
=========================

Place the following icon files here (generated from favicon.svg or logo.png):

  favicon.ico          — Multi-size ICO (16x16, 32x32, 48x48)
  favicon-16x16.png    — 16x16 PNG favicon
  favicon-32x32.png    — 32x32 PNG favicon
  apple-touch-icon.png — 180x180 PNG for iOS
  icon-72x72.png       — PWA icon
  icon-96x96.png       — PWA icon
  icon-128x128.png     — PWA icon
  icon-144x144.png     — PWA icon (Windows tile)
  icon-152x152.png     — PWA icon (iOS)
  icon-192x192.png     — PWA icon (maskable)
  icon-384x384.png     — PWA icon
  icon-512x512.png     — PWA icon (maskable)

TOOL TO GENERATE ALL ICONS FROM SVG:
  Use: https://realfavicongenerator.net
  Or:  npx pwa-asset-generator favicon.svg ./icons --manifest manifest.json

All icons should use the VisionQast orange brand color (#f97316).
