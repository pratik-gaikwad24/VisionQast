Firebase Configuration Guide
Follow these steps to connect your Firebase project
1
Create Firebase Project
Go to console.firebase.google.com → Add project → Follow the wizard
2
Enable Authentication
Firebase Console → Authentication → Get Started → Enable Email/Password provider
3
Create Firestore Database
Firebase Console → Firestore Database → Create database → Choose Production mode
4
Get Config Keys
Project Settings (⚙) → Your apps → Add web app → Copy the config object
5
Update firebase-config.js
Edit assets/js/firebase-config.js and replace the placeholder values:
const firebaseConfig = { apiKey: "YOUR_API_KEY", authDomain: "YOUR_PROJECT_ID.firebaseapp.com", projectId: "YOUR_PROJECT_ID", messagingSenderId: "YOUR_SENDER_ID", appId: "YOUR_APP_ID" };
6
Deploy Firestore Security Rules
Install Firebase CLI: npm install -g firebase-tools
Then run from project root: firebase deploy --only firestore:rules
Or paste firestore.rules into Firebase Console → Firestore → Rules
7
Create First Admin User
1. Go to Firebase Console → Authentication → Add user (email + password)
2. Copy the generated UID
3. Go to Firestore → Create collection admins → Add document with ID = your UID:
{ "uid": "YOUR_USER_UID", "email": "admin@visionqast.com", "role": "admin", "permissions": ["all"] }
4. Log in at /admin/
